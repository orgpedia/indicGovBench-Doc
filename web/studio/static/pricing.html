Model Implementation Approaches & Pricing Details

Document processing costs vary widely—from fractions of a paisa per page for open-source OCR tools running on cloud GPUs, to several rupees per page for commercial Vision-Language Models. This guide details how each model was run, its official vendor price, the actual measured cost per page, and links to official pricing sources for every model tested in IndicGovBench-Orders.

5. How Costs Are Calculated from Actual Runs
Formulas implemented in src/indic_gov_bench/eval/pricing_registry.py.
Tracking Actual Usage: Usage is recorded directly from the model output during each test run:
  • AI / Token Models (Gemini, OpenAI, Claude): Tracked using the exact input and output token counts returned by the model API.
  • Document OCR APIs (Sarvam, Mistral, Datalab): Billed by the number of document pages processed.
  • Cloud GPU / Serverless (Modal): Billed by the exact GPU run time (in seconds) and CPU/memory used.
Code implementation: src/indic_gov_bench/eval/pricing_registry.py.
